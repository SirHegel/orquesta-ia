# Memoria de Orquesta IA

Cada archivo `.md` de esta carpeta se inyecta en **todas** las conversaciones,
como contexto permanente. Es lo que Orquesta sabe siempre, sin que se lo repitas.

Reglas:
- Un tema por archivo. Nombres cortos en minúsculas.
- Escribe hechos, no conversaciones.
- Bórralo cuando deje de ser cierto.

Desde el chat: `/memoria` para verla, `/recuerda <hecho>` para añadir,
`/olvida <archivo>` para quitar.

Este README no se inyecta.
